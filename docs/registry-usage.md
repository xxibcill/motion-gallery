# Registry Usage

This document describes how to install pilot animation components from the motion-gallery registry.

## Namespace and URL Pattern

- Namespace: `@motion-gallery`
- Namespaced item URL pattern: `https://<host>/r/@motion-gallery/{name}.json`
- Direct URL pattern (still supported): `https://<host>/r/{name}.json`

The build output includes both paths so namespaced installs and direct URL installs work together.

## Pilot Items

| Item | Description |
|---|---|
| `slide-toggle-switch` | Weighted toggle with track bloom animation |
| `tab-underline-follower` | Animated tab underline with layoutId |
| `ripple-press-button` | Radial ripple feedback with reduced-motion support |
| `copy-confirmation-chip` | Clipboard utility with state flip animation |
| `like-burst-button` | Heart toggle with particle burst effect |

All five require `motion@^12.0.0`.

## Producer Responsibilities

If you host this registry, you are responsible for:

1. Running `pnpm build:registry` after changing installable catalog entries in `lib/installable-catalog.ts` or registry source files under `registry/`.
2. Publishing these generated files:
   - `public/r/<item>.json`
   - `public/r/index.json`
   - `public/r/@motion-gallery/<item>.json`
   - `public/r/@motion-gallery/index.json`
3. Keeping item names stable (`slide-toggle-switch`, etc.) so namespaced installs remain consistent.

`registry.json` is generated by the build script from the catalog-backed source data and should not be manually edited.

## Consumer Setup (`components.json`)

Add a `registries` entry in your target project's `components.json`:

```json
{
  "registries": {
    "@motion-gallery": "https://example.com/r/@motion-gallery/{name}.json"
  }
}
```

Then install by namespaced item key:

```bash
npx shadcn@latest add @motion-gallery/slide-toggle-switch
npx shadcn@latest add @motion-gallery/tab-underline-follower
npx shadcn@latest add @motion-gallery/ripple-press-button
npx shadcn@latest add @motion-gallery/copy-confirmation-chip
npx shadcn@latest add @motion-gallery/like-burst-button
```

## Optional Thin Wrapper CLI

This repository also provides a small convenience wrapper that delegates to `shadcn add`.

```bash
pnpm motion-gallery list
pnpm motion-gallery add slide-toggle-switch
pnpm motion-gallery add @motion-gallery/tab-underline-follower --dry-run
```

- `list` shows pilot items available in the registry.
- `add` resolves bare item names to `@motion-gallery/<name>` and then runs `shadcn add`.
- The wrapper does not replace the registry model; it only forwards to the existing install flow.

## Direct URL Install (No Namespace Config)

If you do not want `components.json` namespace config, you can still install via direct URL:

```bash
npx shadcn@latest add https://example.com/r/slide-toggle-switch.json
```

## Dependencies

Install declared item dependencies before use:

```bash
pnpm add motion@^12.0.0
```

## Building the Registry

Run:

```bash
pnpm build:registry
```

This regenerates both direct and namespaced output paths under `public/r/`.
